# Design

Visual material that is decided but not yet applied, or applied and worth keeping
as the reference for what was decided.

## `2026-08-25-direzioni-visive.html`

Three visual directions for the app — "Studio" (sober contemporary, petrol),
"Biblioteca" (warm editorial, bordeaux), "Tavolo tecnico" (dense keyboard-first,
IBM Plex) — each applied to the same two real surfaces, a dossier card and the
reading view of an article, in light and dark. Open it in a browser.

**Status: parked, not rejected.** They were prepared at the start of the Round 1
UI work, before the owner clarified that what felt unprofessional was the
*organisation of the data*, not the palette. Round 1 therefore fixed information
architecture and left the visual language alone. Reopen this file when the data
side is settled and the question becomes "how should it look".

The page also records, at the top, the audit finding behind it: the fonts the app
declares (Inter, Merriweather) are never actually loaded, so it renders in system
faces. That is still true, and is the cheapest single visual improvement
available whenever a visual round starts.
